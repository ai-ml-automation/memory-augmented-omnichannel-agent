# memory-augmented-omnichannel-agent
Memory-Augmented Omnichannel Agent — Омниканальный AI-агент с долговременной памятью на базе Mem0 и LangGraph. Извлекает структурированные факты из диалогов, хранит их в Qdrant и Neo4j, использует для персонализации ответов и бесшовного перехода между каналами. Сокращает повторные обращения на 70%, повышает NPS на 5–10 пунктов.
